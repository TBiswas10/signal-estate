Quick Guide: Where To Click, What To Trust, What To Do Next

Use this page as your operating map. The platform is built for advanced investors, so the fastest approach is to run a fixed workflow each time: scan, underwrite, stress, compare, execute.

5-Step Workflow

1. Market Filter Start in Trending and Deals to find candidates with high score, yield, and momentum alignment.
2. Underwrite Asset Select a property, run valuation, then launch research to inspect costs, serviceability, and confidence.
3. Stress Test Use Calculators and Strategy to run rate and rent downside scenarios before commitment.
4. Portfolio Check Run portfolio-risk simulation to avoid concentration and unstable drawdown profiles.
5. Execute Push finalists into Watchlist and Pipeline, then generate a report artifact for decision review.

Tab Map

  • Market: Trending, Deals, News, Comps for discovery and context.
  • Analysis: Comparison, Calculators, Monitor, Strategy, Briefs for due diligence.
  • Execution: Pipeline, Watchlist, Reports for workflow and output.

Speed Keys

  • Ctrl+K opens command palette.
  • Alt+1..9 jumps to tab within current group.
  • Alt+Arrow cycles tabs quickly.
  • Alt+G cycles Market/Analysis/Execution groups.

Interpretation Rules

  1. Treat valuation confidence under 60% as tentative, not decision-grade.
  2. Use scenario downside before upside to avoid optimism bias.
  3. Cross-check score with liquidity and macro sensitivity before pipeline promotion.
  4. Keep assumptions explicit so reports remain auditable.

First Session Checklist

  1. Pick one suburb from Trending and open one candidate property.
  2. Run valuation and research pack.
  3. Run one adverse scenario in Calculators.
  4. Add one asset to Watchlist and one to Pipeline.
  5. Export one report template for review.

Tip: Repeat this checklist for 3 properties and compare outcomes. Pattern recognition starts appearing quickly.
